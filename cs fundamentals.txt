### Operating Systems:

- kernel: managers hw and system calls.

- system calls: interface bw user and os kernel. when program need to perform low level operation that requires access to hw or any resource, it makes system call. eg-> fork, exit, wait, exec, open, close read, write, malloc.

- a process is an instance of a program in execution. it has it's own memory space, resources and state.
- thread is lightweight unit of execution within a process. 

# process vs thread:
- memory : has separate memory space || shares memory with parent process
- communication: used inter process comm || direct memory access
- context switching: expensive || lightweight 

- Deadlock: occurs when multiple processes hold resources and wait for each other to release them. Prevent by: mutual exclusion, hold and wait, no preemption, circular wait.

- virtual memory: it allows a process to use more memory than physically available by swapping pages bw ram and disk.
- paging: divides memory into fixed sized pages and maps them physical frames. 
- segmentation: divides memory into variable-sized logical segments. 

- context switching: when cpu saves the state of current process and loads the state of another. Happens in mulit-tasking, interrupt handling. 

- trashing: occurs when system spends more time in swapping pages in and out of memory than executing process. Caused due to insufficient RAM. Can be solved using: increasing amount of physical memory, use better page replacement algo like LRU. Leads to belady's anamoly.

- RAID: (redundant array of independent disks): storage technology that combines multiple disks to improve  performance. 

- starvation: when a process does not get access to resouces for a long time
- ageing: prevents starvation by gradually increasing process priority.


# Paging:
- it is memory management technique where the process is divided into fixed sized pages and loaded into frames in physical memory 
- it eliminates external fragmentation  but causes internal frag. when the page size is larger than required

# Segmentation:
- Segmentation in an operating system (OS) is a memory management technique that divides a program into segments. 

# paging vs segmentation: 
- basis: 	fixed size pages 	|| variable size pages
- frag: 	internal 		|| external
- speed: 	faster (fixed sized lookups) || slower (variable sized lookups)
- example: 	virtual memory 		|| code, stack 

# Internal Fragmentation:
- Wasted memory inside allocated blocks (due to fixed-size partitioning).
- Example: Allocating 4KB for a 3KB file.

# External Fragmentation:
- Free memory is scattered in small chunks, making it unusable for large requests.
- Solved by compaction or paging.

# Race conditions:
- race condition occurs when multiple threads/processes shared data concurrently leading to unexpected behaviour
- Prevention: 
	- mutex (locks) : allows only one thread to access the critical section
	- semaphores: 	counting mechanisms to control resource access
	- monitors: 	high level abstraction for sync 

# Deadlock:

Deadlock occurs when four conditions hold simultaneously:

- Mutual Exclusion – Only one process can use a resource at a time.
- Hold and Wait – A process holding resources is waiting for additional resources.
- No Preemption – A resource cannot be taken away from a process forcefully.
- Circular Wait – A circular chain of processes exists, each waiting for a resource held by the next.


# Virtual memory:
- allows program to use more memory than physically available by using disk space as an extension of RAM 

# Demand Paging:
- pages are loaded into RAM only when needed (on page fault)
- uses page table to map virtual addresses to physical addresses

# Semaphore:
- semaphore is a signaling mechanism the controls multiple threads/processes accessing a shared resource

### DBMS:

- ACID: atomicity, consistency, isolation, durability.

Atomicity – All operations succeed or fail together.
Consistency – Data remains valid before and after the transaction.
Isolation – Concurrent transactions don’t interfere.
Durability – Once committed, changes persist even after a crash.

START TRANSACTION;
UPDATE accounts SET balance = balance - 100 WHERE id = 1;

COMMIT; -- Ensures Atomicity & Durability

    sale_id INT PRIMARY KEY,

    customer_id INT NOT NULL,

CREATE INDEX idx_sales_customer ON sales(customer_id);
CREATE INDEX idx_sales_region ON sales(region);

### TRANSACTIONS:
- a transaction is a logical unit of work that contains one or more sql statements. it should follow acid properties. 
- Commit makes all changes in txn permanent
- Rollback undoes all the changes in current transaction 

# Reads;
- Dirty read: reading uncommited data that may be rolled back
- Non-repeatable read: getting diff values when reading same data multiple times in a txn
- Phantom Read: seeing new rows in subsequent reads that weren't there initially 

EXAMPLE: 
 
BEGIN TRANSACTION 
UPDATE Accounts SET balance = balance - 100 WHERE account_id = 'A'
UPDATE Accounts SET balance = balance + 100 WHERE account_id = 'B'

IF @@ERROR = 0
	COMMIT; 
ELSE 
 	ROLLBACK;
END IF

### Computer Networks:

# tcp vs udp
- establish connection before communication || sends packets without prior connection
- slower due to reliability mechanisms || no guarantee of delivery


- subnet is logical division of IP network. It reduces congestion, enhances security by isolating network segments. 


- NAT (network address translation) translates pvt IP addresses to public IP addresses for communication over the internet. 

- Firewall is a network security device that monitors and controls incoming and outgoing traffic bases on pre-defined rules. 

- DDoS (distributed denial of service) attack overwhelms server with traffic from multiple sources, making it unavailable. 

- SSL/TLS (secure socket layer/transport layer security) is a cryptographic protocol used to secure communication over the internet. 
  Working:
  - client and server perform a handshake to establish a secure connection. 
  - server send it's ssl certificate to the client 
  - client verifies the certificate and generates session key. 
  - all data is encrypted using session key.


- MAC address: a hw address assigned to a network interface. It is unique and permanent. Used for communication within the same network. 
- IP address: a logical address assigned to a device in a network. Can change. Used for communication across networks.

MUTEX IMPLEMENTATION 

#include <iostream>
#include <thread>
#include <mutex>

std::mutex mtx; // Mutex object

void printData(int id) {
    mtx.lock();  // Locking the mutex
    std::cout << "Thread " << id << " is in the critical section.\n";
    std::this_thread::sleep_for(std::chrono::seconds(1));
    std::cout << "Thread " << id << " is leaving the critical section.\n";
    mtx.unlock();  // Unlocking the mutex
}

int main() {
    std::thread t1(printData, 1);
    std::thread t2(printData, 2);

    t1.join();
    t2.join();

    return 0;
}

#include <iostream>
#include <thread>
#include <semaphore>
using namespace std;

counting_semaphore<2> sem(2); // semaphore with 2 avl resources

void accessResource(int id) {

	sem.acquire(); // wait operation
	cout<<"Thread " << id<< " is accessing resource\n";
	cout<<"Thread " << id<< " is releasing resource\n";
	sem.release();
}

	thread t1(accessResource(1));
	thread t1(accessResource(2));
	thread t1(accessResource(3));

	t1.join();

}
